7. Data Analysis VS Data Analytics
-----------------------------------------------------------

These Terms are related but not exactly the same.
--------------------------------------------------------------------------
Data Analysis:

Focuses mainly on
	Understanding and examining data to generate insights.
-------------------------------------------------------------
Data Analytics
------------------------
is broader and can includes:

> Data Collection
> Data preparation
> Data analysis
> Visualization
> Statistical Analysis
> Predictive Analysis
> Business Decision-Making
-------------------------------------------------

Data Analysis = Analyze the data

Data Analytics = Complete process of using data to generate insight and support decision.
----------------------------------------------------------------------------------------------------

8. Types of Data Analysis
-------------------------------------------------------
There are four commonly categories:

1. Descriptive Analysis
	What happened?

	>> Sales where 50 lakes in 2025

2. Diagnostic Analysis 
	Why did it happen?

	Sales decreased because product availability was low

3. Predictive Analysis
	What might happen?

	Sales may increase by 15% next month


4. Prescriptive  Analysis
What should we do?

	Increase inventory and run a promotional campaign.

1. What is NumPy?
----------------------------------------------------
NumPy = Numerical Python
---------------------------------------
NumPy is a Python Library used for:

* Numerical calculations
* Array operations
* Mathematical Operations
* Statistical calculations
* Matrix Operations
* Scientific computing
* Data Analysis
* Machine Learning
-------------------------------------------------------------------------------------
The main object NumPy is NumPy array (ndarray)
-----------------------------------------------------------------------------------------------------
Installation of NumPy
---------------------------------------------------
open CMD:  pip install numpy
-----------------------------

#### Why Do we need NumPy?
-------------------------------------
Python Provides Lists:

numbers = [10,20,30,40]

But NumPy provides highly optimized arrays.

import numpy as np
numbers = np.array([10,20,30,40])


------------------------------------------------------

NumPy arrays are designed for numerical operations and generally provide much faster, more memory efficient operations than ordinary python lists for large numerical dataset.

---------------------------------------------------------------------------------------------------

DESCRIPTION
    NumPy
    =====

    Provides
      1. An array object of arbitrary homogeneous items
      2. Fast mathematical operations over arrays
      3. Linear Algebra, Fourier Transforms, Random Number Generation


3. NumPy vs Python Lists
--------------------------------------------------------
Python List:

numbers = [10,20,30,40]
print(numbers)

output
[10,20,30,40]

-------------------------------
NumPy Array


arrayNumbers = np.array([10,20,30,40])
print(arrayNumbers)

Output
------
[10 20 30 40]
------------------------------
Import Difference
-------------------
a = [1,2,3]
b = [4,5,6]
print(a+b)

# here + joins the lists

[1, 2, 3, 4, 5, 6]
------------------------------------------------
a = np.array([1,2,3])
b = np.array([4,5,6])
print(a+b)

## Here NumPy performs element-wise addition

[5 7 9]
